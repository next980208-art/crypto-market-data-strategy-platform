# Report snapshots

These JSON files are read-only snapshots from the frozen-rule forward observation.

- `forward_observation_snapshot.json`: data volume, simulated trades, cost-case returns, drawdown, and the `no_trade` decision.
- `weekly_evaluation_snapshot.json`: weekly persistence checks and 13 data/safety quality checks.

They are evidence of the reported result, not a profitability guarantee or live fill record. The original runtime database, raw market data, logs, and credentials are intentionally excluded.
